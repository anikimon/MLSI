# Проверка материалов по указу № 809

Сервис анализирует материалы — тексты, аудио, видео — на соответствие Основам
государственной политики по сохранению и укреплению традиционных российских
духовно-нравственных ценностей (Указ Президента РФ от 09.11.2022 № 809) и формирует
подробный покомпонентный отчёт: что соответствует, что вызывает вопросы и что
не соответствует, с цитатами и уровнем уверенности.

> **Важно.** Указ № 809 — документ стратегического планирования, а не перечень прямых
> запретов. Сервис даёт **аналитическую подсказку**, не юридическое заключение;
> итоговое решение принимает человек. Формулировки и оценки носят вспомогательный характер.

Backend — Python 3.10+ на стандартной библиотеке, данные — SQLite. Для аудио и видео
дополнительно нужны `ffmpeg` и `faster-whisper`.

## Запуск

```sh
python server.py
```

Откройте `http://127.0.0.1:8300`.

Переменные окружения:

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `HOST` / `PORT` | адрес и порт | `127.0.0.1:8300` |
| `COMPLIANCE_DB` | путь к SQLite | `data/compliance.db` |
| `UPLOAD_DIR` | каталог загруженных файлов | `data/uploads` |
| `MAX_UPLOAD_MB` | максимальный размер файла | `100` |
| `ASR_MODEL` | модель faster-whisper | `small` |
| `ASR_ENABLED` | `0` — отключить распознавание речи | `1` |
| `MEDIA_TIMEOUT` | таймаут ffmpeg, сек | `600` |
| `VISION_API_BASE` / `VISION_API_KEY` / `VISION_MODEL` | OpenAI-совместимый vision-эндпоинт для анализа кадров | не заданы |

## ИИ

Положите ключ DeepSeek в `key.txt` рядом с `server.py` или задайте `DEEPSEEK_API_KEY`.
Без ключа работают локальные правила (лексиконы ценностей и рисков, детектор
ненормативной лексики) — отчёт помечается как локальный.

## Как устроена проверка

Рубрика выведена из текста указа (`rubric.py`) и состоит из четырёх разделов:

- **п.5 «Традиционные ценности»** — 17 ценностей: жизнь, достоинство, права и свободы,
  патриотизм, гражданственность, служение Отечеству, высокие нравственные идеалы,
  крепкая семья, созидательный труд, приоритет духовного над материальным, гуманизм,
  милосердие, справедливость, коллективизм, взаимопомощь и взаимоуважение,
  историческая память, единство народов России.
- **п.14 «Деструктивная идеология»** — маркеры, пропаганда которых является несоответствием.
- **п.17 «Риски»** — восемь рисков (а–з).
- **п.24 «Язык и историческая правда»** — ненормативная лексика, излишняя иностранная
  лексика, фальсификация истории.

Для каждого пункта агент выставляет один из статусов: `соответствует`,
`частично соответствует`, `не соответствует`, `не применимо`, — с уверенностью 0–1,
цитатами и комментарием. Раздел обрабатывает отдельный агент; разделы анализируются
параллельно. Агент-аналитик сводит результаты в индекс соответствия и текстовые выводы.

## Обработка материалов

| Тип | Что происходит |
| --- | --- |
| Текст (вставка) | анализ напрямую |
| `.txt`, `.md` | декодирование и анализ |
| `.docx` | извлечение текста из XML (без внешних библиотек) |
| `.html`/`.htm` | очистка разметки |
| Аудио (`mp3`, `wav`, `ogg`, `m4a`, `aac`, `flac`, `opus`) | ffmpeg → WAV 16 кГц → faster-whisper (рус.) → анализ |
| Видео (`mp4`, `mov`, `avi`, `mkv`, `webm`) | извлечение аудио → расшифровка → анализ; плюс кадры для визуального анализа |

Визуальный анализ кадров выполняется только если настроен vision-эндпоинт
(`VISION_API_BASE`, `VISION_API_KEY`); иначе в отчёте будет пометка, что визуальный
анализ недоступен. PDF напрямую не читается — загрузите DOCX/TXT.

## Установка компонентов

```sh
python -m pip install faster-whisper
```

`ffmpeg` устанавливается отдельно и должен быть доступен в `PATH`.

## Ограничения

- Оценки основаны на извлечённом тексте и кадрах; ирония, контекст и визуальный ряд
  могут распознаваться неверно.
- Указ не является перечнем запретов: «несоответствие» здесь означает наличие тем,
  отнесённых указом к рискам, а не нарушение закона.
- Сервис не содержит аутентификации и рассчитан на локальный/доверенный контур.
- Загруженные файлы хранятся в `data/uploads`; контролируйте доступ и место на диске.
