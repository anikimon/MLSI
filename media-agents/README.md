# Сеть ИИ-агентов для анализа зарубежных СМИ

Веб-панель, в которой несколько специализированных ИИ-агентов совместно анализируют
новости зарубежных СМИ: переводит материал, оценивает тональность, определяет уровень
агрессии и объект агрессии, а агент-аналитик формирует сводные выводы по всей выборке.

Backend — Python 3.10+ на стандартной библиотеке, данные — SQLite, обязательных
внешних зависимостей нет.

## Запуск

```sh
python server.py
```

Откройте `http://127.0.0.1:8200`.

Переменные окружения:

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `HOST` | адрес прослушивания | `127.0.0.1` |
| `PORT` | порт | `8200` |
| `MEDIA_DB` | путь к файлу SQLite | `data/media.db` |
| `ANALYZE_BATCH_LIMIT` | максимум материалов за один запуск анализа | `10` |
| `DEEPSEEK_MODEL` | модель DeepSeek | `deepseek-chat` |

## Как работает сеть агентов

Для каждого материала оркестратор запускает цепочку агентов:

1. **Переводчик** (`TranslatorAgent`) — переводит заголовок и текст на русский.
2. **Тональность** (`TonalityAgent`) — метка `negative/neutral/positive` и оценка от −1 до 1.
3. **Уровень агрессии** (`AggressionAgent`) — шкала 0–10, где 0 — спокойная информация,
   10 — прямая враждебность, угрозы или призывы к насилию.
4. **Объект агрессии** (`TargetAgent`) — против кого или чего направлен посыл
   (страна, организация, персона, группа).
5. **Аналитик** (`SummaryAgent`) — по агрегированным показателям всей выборки формирует
   выводы: общий уровень агрессии и тональность, ключевые объекты, самые агрессивные
   источники и материалы.

Агенты анализа тональности, агрессии и объекта работают параллельно, каждый обращается
к модели со своей ролью и возвращает строгий JSON. Если ключ DeepSeek не задан или
недоступен, каждый агент переключается на локальные правила (лексиконы, подсчёт
маркеров, распознавание акторов) — панель остаётся работоспособной офлайн.

## Включение ИИ DeepSeek

Положите ключ в `key.txt` рядом с `server.py` или задайте переменную окружения:

```powershell
$env:DEEPSEEK_API_KEY = "ваш_ключ"
python server.py
```

Без ключа агенты используют локальные эвристики, а сводный отчёт помечается как
рассчитанный без ИИ.

## Источники новостей

- **RSS-ленты.** При первом запуске добавляются источники по умолчанию (BBC World,
  CNN World, Reuters, Deutsche Welle, Al Jazeera, The Guardian, Le Monde, El Pais).
  Их можно удалять и дополнять своими на вкладке «Источники». Для загрузки нужен
  доступ в интернет с машины, где запущен сервер.
- **Ручная вставка.** На вкладке «Лента» можно вставить заголовок, источник и текст
  новости и проанализировать его без сети.

Материалы дедуплицируются по отпечатку (источник + заголовок + ссылка), повторный сбор
не создаёт копий.

## Основные endpoints

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/health` | статус и наличие ключа ИИ |
| GET/POST | `/api/feeds` | список и добавление RSS-источников |
| DELETE | `/api/feeds/{id}` | удалить источник |
| POST | `/api/collect` | собрать новости (все источники или `feed_id`) |
| GET | `/api/articles?only=all\|analyzed\|unanalyzed` | лента материалов |
| POST | `/api/articles` | добавить материал вручную |
| DELETE | `/api/articles/{id}` | удалить материал |
| POST | `/api/articles/{id}/analyze` | прогнать сеть агентов по одному материалу |
| POST | `/api/analyze` | проанализировать пачку новых материалов |
| GET | `/api/stats` | агрегированная сводка |
| GET/POST | `/api/reports` | список и генерация аналитического отчёта |
| GET | `/api/reports/{id}` | сохранённый отчёт |

## Ограничения

- Агенты анализируют **только предоставленный текст** и не проверяют факты и внешние
  источники; оценки носят вспомогательный характер и не заменяют редакционную экспертизу.
- RSS-источники могут блокировать загрузку или менять формат — ошибки по каждому
  источнику показываются в панели.
- Сервис не содержит аутентификации и рассчитан на локальный или доверенный контур.
  Не публикуйте встроенный HTTP-сервер в интернет напрямую; для внешнего доступа
  используйте HTTPS-прокси.
- Делайте резервные копии файла базы данных.
