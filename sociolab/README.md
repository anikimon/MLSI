# Социологическая лаборатория

Веб-сервис для социологической лаборатории: вход по почте и паролю с двухфакторной
аутентификацией, конструктор опросов, ИИ-аналитика в карточке исследования и управление
сотрудниками. Backend — Python 3.10+ на стандартной библиотеке, данные — SQLite,
обязательных внешних зависимостей нет.

## Запуск

```sh
python server.py
```

Откройте `http://127.0.0.1:8100`. При первом входе создайте учётную запись
администратора — первому пользователю автоматически выдаётся роль `admin`.

Переменные окружения:

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `HOST` | адрес прослушивания | `127.0.0.1` |
| `PORT` | порт | `8100` |
| `LAB_DB` | путь к файлу SQLite | `data/lab.db` рядом с `server.py` |
| `COOKIE_SECURE` | `1` — cookie только по HTTPS | `0` |
| `ALLOW_DEV_CODES` | `1` — отдавать тестовый код в ответе, если SMTP не настроен | `0` |

## Двухфакторная аутентификация (email)

Первый шаг — почта и пароль. Затем сервер создаёт шестизначный код, сохраняет его
хеш и отправляет письмо через SMTP. Вход завершается только после верного кода
(`POST /api/login` → `POST /api/login/verify`). Код действует 10 минут, допускается
не более 5 попыток, после пароля действует ограничение на количество неудачных входов.

Настройте SMTP через окружение:

```powershell
$env:SMTP_HOST = "smtp.yandex.ru"
$env:SMTP_PORT = "587"
$env:SMTP_USER = "lab@example.com"
$env:SMTP_PASSWORD = "пароль-приложения"
$env:SMTP_FROM = "lab@example.com"
$env:SMTP_STARTTLS = "1"
python server.py
```

Для неявного SSL укажите `SMTP_SSL=1` и порт `465`, для STARTTLS — `SMTP_STARTTLS=1`
и порт `587`. Пароль рекомендуется хранить как секрет окружения, а не в коде.

Если `SMTP_HOST` не задан, сервер печатает код в консоль — это режим разработки.
Чтобы получать код в ответе API для автотестов, задайте `ALLOW_DEV_CODES=1`
(в рабочей среде включать не следует).

## Конструктор опросов

Поддерживаются четыре типа вопросов:

- `open` — открытый ответ (текст);
- `single` — один вариант из списка;
- `multiple` — несколько вариантов;
- `scale` — числовая шкала с границами и шагом.

Анкету можно менять только до первого собранного ответа — после начала сбора
формулировки блокируются, чтобы не нарушить данные.

## ИИ-аналитика

В карточке исследования вкладка «Аналитика» показывает распределения по вопросам и
аналитическую записку. Нажмите «Сгенерировать ИИ-анализ»: сервер отправляет в
DeepSeek только агрегированные и обезличенные показатели (числа, доли, средние),
без текстов открытых ответов и персональных данных. Записка сохраняется в карточке.

Чтобы включить ИИ, положите ключ DeepSeek в `key.txt` рядом с `server.py` или задайте:

```powershell
$env:DEEPSEEK_API_KEY = "ваш_ключ"
python server.py
```

Без ключа кнопка формирует локальный аналитический обзор на основе распределений —
функция остаётся работоспособной офлайн.

## Сотрудники исследования

В разделе «Команда» администратор создаёт учётные записи и назначает роли:
`admin`, `researcher`, `interviewer`. В карточке исследования вкладка «Команда»
позволяет назначать и снимать сотрудников с конкретного исследования.

- `admin` — управляет командой и удаляет исследования;
- `researcher` — создаёт исследования, ведёт анкету, аналитику и состав команды;
- `interviewer` — заполняет анкеты, но не видит аналитику и список ответов.

## Безопасность

- Сервер использует встроенный `http.server` — не публикуйте его напрямую в интернет.
  Для внешнего доступа ставьте за HTTPS-прокси и включайте `COOKIE_SECURE=1`.
- Cookie сессии `HttpOnly` + `SameSite=Lax`, сессии хранятся в виде хешей.
- Пароли — PBKDF2-SHA256 (240 000 итераций), коды 2FA — только в виде хешей.
- Делайте резервные копии файла базы данных.
