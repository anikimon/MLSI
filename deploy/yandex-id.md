# Вход через Yandex ID

Позволяет сотрудникам входить без пароля. **Новые аккаунты не создаются автоматически**: доступ
получает только тот, чей email уже добавлен администратором в разделе «Команда».

## 1. Создать приложение в Яндекс OAuth

1. Откройте https://oauth.yandex.ru/ и нажмите «Создать приложение».
2. Название — любое (например, `MLSI`), платформа — **Веб-сервисы**.
3. **Redirect URI**: `https://mlsilab.ru/api/auth/yandex/callback`
4. В разделе **Доступ к данным** добавьте права:
   - `login:email` — доступ к email
   - `login:info` — доступ к имени и логину
5. Сохраните. Скопируйте **ClientID** и **Client secret**.

## 2. Прописать в окружении сервера

В `/etc/mlsi.env`:

```
YANDEX_CLIENT_ID=<ClientID>
YANDEX_CLIENT_SECRET=<Client secret>
YANDEX_REDIRECT_URI=https://mlsilab.ru/api/auth/yandex/callback
```

```sh
systemctl restart mlsi
```

Если переменные пустые — кнопка «Войти через Яндекс» не показывается.

## Как это работает

- На экране входа появляется кнопка «Войти через Яндекс» (если вход настроен).
- Кнопка ведёт на `GET /api/auth/yandex/start` → 302 на `oauth.yandex.com/authorize`.
- Яндекс возвращает браузер на `GET /api/auth/yandex/callback?code=&state=`.
- Сервер меняет код на токен, получает email и **ищет пользователя с таким email**.
  - Найден → создаётся сессия, ставится cookie, редирект на `/`.
  - Не найден → редирект на `/?auth=yandex_denied` с подсказкой обратиться к администратору.
- `state` защищает от CSRF (живёт 10 минут в памяти процесса).
